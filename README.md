# formulario-cadastro-responsivo
Projeto de estudo desenvolvido com base em um tutorial, para praticar HTML, CSS e JavaScript e colocar meus conhecimentos em prática.
# Funcionalidades
- Formulário de cadastro com validação de campos
- Layout responsivo (adapta a diferentes tamanhos de tela)
- Alternância na visibilidade da senha (mostrar/ocultar)
